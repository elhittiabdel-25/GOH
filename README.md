# Gate of Hope: donations app

A mobile app (installable from the browser on Android and iPhone) for following Gate of Hope's
fundraising cases. **The Google Sheet stays the master record**: the app reads and writes directly in it,
and changes made by hand in the sheet show up in the app.

- **Admins** record donations, create, edit and close cases.
- **Members** see the case cards (progress, amount collected, amount remaining), updated automatically.
- Costs nothing: Google Apps Script (free) + GitHub Pages (free). No app store needed.

```
Phone (app)  ⇄  Google Apps Script (API, attached to the sheet)  ⇄  Google Sheet
docs/           apps-script/                                        PROJETS CLAUDE, DONS, …
```

## Tabs in the Google Sheet

| Tab | Purpose |
|---|---|
| `PROJETS` / `PROJETS.OLD` | **Never modified** by the app (kept for reference). |
| `PROJETS CLAUDE` | Active cases. Columns: ID, type, description, budget, collected (formula), remaining (formula), situation, cycle, opened on, updated on, **responsible**. |
| `PROJETS.OLD CLAUDE` | Closed cases (history), with ID, cycle and responsible. |
| `DONS` | One line per donation: date, case ID, cycle, amount, donor, payment method, note, entered by, cancelled, **who has the money**. |
| `MOUVEMENTS` | Money changing hands: from one member to another, or handed to the beneficiary. |
| `MEMBRES` | Who can use the app: name, email, role (`admin` / `membre`), access code, active (`OUI` / `NON`). |
| `JOURNAL APP` | Log of every action taken from the app. |

**IDs and cycles.** Each case/beneficiary has a permanent ID (`MED-003`, `FML-001`, `PUI-002`…; the prefix
comes from the case type). When a case returns, it keeps its ID and a new **cycle** begins (collection no. 1, 2, 3…).
"Montant collecté" is a formula: the sum of the non-cancelled donations in `DONS` for that ID and cycle.

### Working directly in the sheet (everything stays in sync)

- **New case**: add a line in `PROJETS CLAUDE` (type + description + budget). The ID, cycle, date
  and formulas fill in automatically. For a returning case, first type its existing ID in column A.
- **Donation**: add a line in `DONS` with the date, the case ID and the amount; the rest fills in by itself.
- **Amount typed by hand** in "Montant collecté": it is turned into an adjustment line in `DONS`
  (so nothing is lost) and the formula is put back.
- **Close a case**: select its line, then menu **Gate of Hope → Clôturer la collecte sélectionnée**.
  It moves to `PROJETS.OLD CLAUDE`.
- **Add a member**: a new line in `MEMBRES` (name, email, role). An access code is generated by itself.
  To revoke access: `Actif` = `NON`.

## Visitor access

On the sign-in screen, **"Continuer en tant que visiteur"** opens the app without email or code, **read-only**:
the case cards (description, situation, amounts) only. Visitors never see donations, donors, members or who
holds the money, and cannot change anything. To switch it off (or back on): menu
**Gate of Hope → Accès visiteur : activer / désactiver** in the sheet. It is on by default.

## Who has the money

The app tracks **who holds the money, and for which case**:

- When a donation is recorded, the form asks **"Qui a l'argent ?"** (the person who received it;
  defaults to whoever enters the donation). It goes into the last column of `DONS`.
- Each case can have a **responsible** (the member who launched it), shown on its card.
- **"Remettre…"** records money changing hands: to another member (e.g. to the case's responsible) or
  **to the beneficiary** (money spent for the case). One line per move in `MOUVEMENTS`.
  Nobody can hand over more than they hold for that case. A wrong move can be cancelled.
- **My account** (profile icon) shows "Mon argent": how much I hold and for which cases.
  Admins also see **"Qui a quoi"** for everyone. A plain member only sees their own money.
- Donations recorded before this feature (or typed in the sheet without a name) count as
  **"Non attribué"**. They can be attributed to someone later with "Remettre…".
- Closing a case while someone still holds money for it shows a warning; the money stays visible
  in that person's profile until it is handed over.

The new columns are added **to the right** of the existing ones: the formulas for "Montant collecté"
and "Reste" do not read them, so amounts are unchanged. Names come from the `MEMBRES` tab: set
everyone's real name there (e.g. replace "Administrateur") **before** using the feature.

**Upgrading an existing install (v1.0 → v1.1):** paste the new `Code.gs`, then
**Deploy → Manage deployments → ✏️ → Version: New version → Deploy**. The columns and the
`MOUVEMENTS` tab are created automatically on the first use (or via the menu
**Gate of Hope → Vérifier / réparer les onglets**). Update the script **before** the app; the app
hides the new screens until the script is updated, and older app versions keep working.

## Installation (about 15 minutes, once)

### 1. Install the script in the Google Sheet
1. Open the "Collectes Gate of Hope" Google Sheet → **Extensions → Apps Script**.
2. Replace the contents of `Code.gs` with [apps-script/Code.gs](apps-script/Code.gs) (button "Copy raw file").
3. Click **+ → Script**, name it `Migration`, and paste [apps-script/Migration.gs](apps-script/Migration.gs).
4. ⚙️ **Project settings** → time zone **(GMT+01:00) Casablanca**.
5. 💾 Save. Back in the sheet, **reload the page**: a **Gate of Hope** menu appears.
6. **Gate of Hope → Installer (première fois uniquement)**. Google asks for authorization:
   *Continue → choose your account → Advanced → Go to (unsafe project) → Allow*
   (this warning is normal for a personal script).
7. A message confirms the installation and shows **your admin access code** (also in the `MEMBRES` tab).

### 2. Publish the API
1. In Apps Script: **Deploy → New deployment** → type **Web app**.
2. *Execute as*: **Me**. *Who has access*: **Anyone**. → **Deploy**.
3. Copy the **Web app URL** (`https://script.google.com/macros/s/…/exec`).
   ("Anyone" only opens the door to the app: without a valid email + code, no data is returned.)

### 3. Connect the app
Paste the URL into [docs/config.js](docs/config.js) (`API_URL: '…'`), either by editing the file on GitHub (✏️)
or by sending it to Claude. The app is published at **https://elhittiabdel-25.github.io/GOH/**.

### 4. On each phone
Open the address above, sign in with email + code, then:
- **iPhone (Safari)**: Share → *Add to Home Screen*.
- **Android (Chrome)**: menu ⋮ → *Install app* (or the "Installer" banner).

### Updating the script later
Paste the new code, then **Deploy → Manage deployments → ✏️ → Version: New version → Deploy**.
The URL stays the same.

## Android app

The web app (`docs/`) is packaged as a native Android app with [Capacitor](https://capacitorjs.com)
(`android/` folder). **GitHub Actions builds it automatically** on every change to the app
(*Actions* tab → "Application Android") and publishes it under **Releases**:

- `GateOfHope.apk`: to install directly on a phone (free).
  Permanent download link: **https://github.com/elhittiabdel-25/GOH/releases/latest/download/GateOfHope.apk**
- `GateOfHope.aab`: the file to upload to the Google Play Store (if you publish there some day).

The app shows "New version available" when a newer release exists.
iPhone users keep the web version installed on their home screen.

### Signing key (once only)
Android requires every version to be signed with **the same key**. It is never stored in this
(public) repository: it lives in the repository's GitHub **secrets**.
Settings → Secrets and variables → Actions → *New repository secret*, add these 4:

| Name | Value |
|---|---|
| `ANDROID_KEYSTORE_BASE64` | contents of the key file encoded in base64 |
| `ANDROID_KEYSTORE_PASSWORD` | key password |
| `ANDROID_KEY_ALIAS` | `gateofhope` |
| `ANDROID_KEY_PASSWORD` | key password (the same one) |

Then *Actions* → "Application Android" → **Run workflow**. Without these secrets, only a test
APK is produced (in the *Actions* tab, not published).
**Keep the `.jks` file and its password somewhere safe** (e.g. a private Google Drive): without them,
you can never ship an update to the installed app again.

### Installing on a phone
1. Open the download link above on the Android phone.
2. Open the downloaded file → allow "Install unknown apps" for the browser (once only).
3. Install. To update: same procedure, with no need to uninstall.

### Google Play Store (optional)
Developer account ($25 once) → create the app → upload `GateOfHope.aab`.
The key above serves as the *upload key*; enable "Play App Signing".

## Development
```bash
npm test          # tests the script on an emulated sheet (fictional data)
npm run dev       # local app at http://localhost:8080 with an emulated API
```
`apps-script/Migration.gs` only holds fingerprints (SHA-256) of the case texts,
so no beneficiary information is published in this repository.
